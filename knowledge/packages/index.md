# Vue packages

* [@teamnovu/kit-animations](animations.md) - scroll-triggered CSS animations via the `v-animate` directive
* [@teamnovu/kit-components](components.md) - accessible Vue components (Collapse, Accordion, Dialog, Image, …)
* [@teamnovu/kit-composables](composables.md) - collapse, accordion, scroll-state and prompt composables
* [@teamnovu/kit-vue-forms](vue-forms.md) - form state and zod validation composables and components

# Nuxt and cookie consent

* [@teamnovu/kit-nuxt](nuxt.md) - Nuxt module that auto-registers the kit components, composables and animations
* [@teamnovu/kit-cookieconsent](cookieconsent.md) - Vue and Nuxt wrapper around vanilla-cookieconsent

# API clients

* [@teamnovu/kit-shopware-api-client](shopware-api-client.md) - fetch-based typed client for the Shopware Store API
* [@teamnovu/kit-shopware-composables](shopware-composables.md) - vue-query composables for the Shopware Store API
* [@teamnovu/kit-operations](operations.md) - vue-query helpers for API Platform endpoints
* [@teamnovu/kit-api-platform-types](api-platform-types.md) - API Platform types and a Vite plugin generating serialization-group types
